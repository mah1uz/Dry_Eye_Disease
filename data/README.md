# Data

The data set is not included. Download it from Kaggle:
https://www.kaggle.com/datasets/dakshnagra/dry-eye-disease

Put the CSV in this folder. The default name used by notebook 02 is `Dry_Eye_Dataset.csv`.
Notebook 01 finds the file on its own: it uses the first CSV in this folder that has the expected columns.

The Kaggle page gives no information on how the data were collected or created.
